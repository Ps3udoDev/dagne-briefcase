# Identidad de Marca — Psicoiris

> **Estilo:** *Serenidad Editorial*  
> **Concepto:** Un espacio de escucha analítica, contención serena y rigor profesional. El nombre **Psicoiris** evoca la unión entre *psique* (mente, mundo interior) e *iris* (luz, matiz emocional, mirada compasiva y puente hacia el bienestar).

---

## 1. Paleta Cromática Oficial (Pasteles Editoriales)

| Token | Hex | Uso Principal |
| :--- | :--- | :--- |
| **Lienzo Puro** | `#FFFFFF` | Fondo base, tarjetas principales, claridad y descanso visual |
| **Rosa Empolvado** | `#F4E6E5` | Bloques reflexivos, citas, badges suaves, halo cálido del logotipo |
| **Lavanda Translúcido** | `#E8D3EC` | Contenedores de enfoque, chips, fondo secundario de icono |
| **Malva Estructural** | `#D4B2D8` | Bordes finos (1px), divisores suaves, trazos secundarios del isotipo |
| **Morado Acento** | `#9F73AB` | Botones primarios, estados activos, acento principal del logotipo |
| **Berenjena Profundo** | `#2D2531` | Tipografía principal (reemplaza al negro puro para lectura descansada) |

## 2. Tipografía

- **Titulares y Marca:** *Newsreader* (Regular 400 / Italic 400 / Medium 500) — aporta calidez literaria y rigor editorial.
- **Cuerpo y UI:** *Plus Jakarta Sans* (400 / 500 / 600) — legibilidad moderna y amable en pantallas móviles y formularios.

## 4. Reglas de Uso

- **Área de respeto:** Mantener un margen libre equivalente al 25% de la altura del isotipo alrededor del logotipo.
- **Fondos permitidos:** Usar preferentemente sobre `#FFFFFF`, `#fff7fc` o `#F4E6E5`. Evitar fondos oscuros saturados o colores neón.
- **No distorsionar:** Mantener proporciones originales y no añadir sombras duras ni contornos negros.
